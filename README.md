# Wireshark Labs

A collection of hands-on Wireshark packet analysis labs created while learning Computer Networking and Cybersecurity.

Instead of only studying networking theory, this repository focuses on observing real network traffic captured from a live system using Wireshark.

Each lab explains:

- The protocol
- Why it exists
- Packet structure
- Important fields
- Real-world use cases
- Packet walkthrough
- Key observations
